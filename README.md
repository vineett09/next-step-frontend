# 🚀 NextStep – AI-Powered Career & Skill Roadmaps

NextStep is a powerful, AI-integrated web application that helps users navigate their tech career journey through dynamic, interactive roadmaps. Whether you're just starting out or pivoting your path, NextStep offers visual guides, personalized AI suggestions, and custom roadmap creation tools to support every step of your journey.

---

## 🧩 Features

- 📚 **Explore Interactive Tech Roadmaps**  
  View skill trees and domain-specific paths using responsive **D3.js tree visualizations**.

- 🔖 **Bookmark & Download**  
  Easily save or download roadmaps for future reference.

- 🤖 **AI-Powered Suggestions**  
  - Generate roadmaps tailored to your experience level.
  - Get career path suggestions based on goals.
  - Receive step-by-step guides to achieve tech roles.

- 💬 **Chatbot Support**  
  Get instant answers to roadmap-related queries using an integrated AI chatbot.

- 🧑‍💻 **Build Your Own Roadmaps**  
  Use **React Flow** to create custom roadmaps and:
  - Save as **Public** or **Private**
  - Share with others or keep for yourself

- 👤 **User Profiles**  
  - Store custom and bookmarked roadmaps
  - Track AI-generated suggestions
  - Manage shared and personal learning paths
